# Tillämpad Maskininlärning med Python 🤖

Detta repository innehåller mina lösningar och kodövningar från kurslitteraturen *"Lär dig AI från grunden - Tillämpad maskininlärning med Python"*.

## 📁 Mappstruktur och Innehåll

* **Kapitel 1 & 2:** Grundläggande ML-flöden, uppdelning av tränings-, validerings- och testdata, samt utvärdering av regressionsmodeller (RMSE).
* **Kapitel 3:** Explorativ dataanalys (EDA) och tillämpad linjär regression (analys av diamantpriser och HR-data).
* **Kapitel 4:** Klassificering. Träning av Random Forest-modeller för att förutsäga personalomsättning samt bildigenkänning (MNIST).
* **Kapitel 5:** Dimensionalitetsreduktion med PCA (Principal Component Analysis) för att optimera och utvärdera datamängder (analys av bilpriser).
* **Kapitel 6:** Oövervakad maskininlärning och Klustring (K-Means). Segmentering av geografiska data (hus i Kalifornien), HR-grupperingar och analys av musikaliska attribut (Spotify 80-talshits).

## 🛠 Tekniker & Verktyg

* **Språk:** Python
* **Bibliotek:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
* **Modeller & Algoritmer:** Linear Regression, Decision Tree Regressor, Random Forest Classifier, PCA, K-Means Clustering
* **Miljö:** Jupyter Notebook i Visual Studio Code
